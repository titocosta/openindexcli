description: Leave an OpenIndex group (rotates keys for remaining members)
argument-hint: <groupName>
allowed-tools: Bash(npx @openindex/openindexcli:*)
---
Leave the OpenIndex group named `$ARGUMENTS`. This triggers a key rotation for
the remaining members. Run:

```bash
npx @openindex/openindexcli leave-group $ARGUMENTS
```

Confirm I have left the group.
